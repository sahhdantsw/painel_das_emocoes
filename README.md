# Painel das Emoções 

## About the Project

The Emotion Panel is a physical assistive device designed to help
literate people with cognitive difficulties communicate through writing
and emotional expression.

The device consists of a 3D-printed structure measuring approximately
29 cm, equipped with a touchscreen and LED indicators representing
different emotions.

## How It Works

The touchscreen runs a Python program with a virtual keyboard,
allowing users to type and communicate through written messages.

The physical device also includes LEDs that represent different
emotional states. These visual indicators provide an additional,
simple way for the user to express how they are feeling.

## Physical Structure

The device was designed and produced using a 3D printer, resulting
in a compact physical panel of approximately 29 cm.

![Emotion Panel](images/painel.jpg)

## Virtual Keyboard

The touchscreen interface includes a virtual keyboard programmed
in Python, allowing users to enter text directly on the device.

## Emotion LEDs

The LEDs integrated into the physical panel represent different
emotions, providing visual feedback and another communication method.
